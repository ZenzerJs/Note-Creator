# Course Materials Directory

Drop any optional supporting course materials here to help the agent produce maximum-fidelity notes:

1. **Course Syllabus / Outline PDF**: Enables the agent to align note topics, mark weightings, calculator policies, and lab expectations.
2. **Textbook PDF (or textbook edition name)**: Allows the agent to cross-reference exact theorem definitions, notation conventions, and assigned chapter problems.
3. **Assigned Homework / Problem Lists**: Enables the agent to generate worked practice problems that mirror what your professor actually tests.
4. **PRACTICE_PROBLEMS.md**: Markdown index of assigned problem numbers per chapter/section.

> **Copyright Note:** PDF files in this directory are gitignored so copyrighted textbooks and institutional documents are not pushed to GitHub.
