# Calendar Schedule Directory

Drop your personal `.ics` calendar export files here.

The agent will automatically read your schedule to:
- Identify upcoming assignment deadlines, quizzes, and midterm dates.
- Correlate lab days and lecture days.
- Tailor alert boxes (`#assignalert`, `#quizalert`) to your actual upcoming course events.

> **Privacy Note:** `.ics` files in this directory are gitignored so your personal schedule is never pushed to public repositories.
